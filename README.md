# Parent Compass

Faceless South African **parent guidance** product you can sell.

**Model:** Free demo static web app + paid Situation Scripts Pack (**R149** on Gumroad).

## Hard safety

- **Not** therapy, counselling, clinical advice, or diagnosis.
- **Not** a substitute for social workers, psychologists, lawyers, or teachers.
- Scenario cards with frameworks only — **not** an AI therapist.
- Adults **18+** only (parents/caregivers).
- Abuse, violence, or child in danger → call **112** · Childline SA **116** (verified toll-free 24h: childlinesa.org.za) · [findahelpline.com](https://findahelpline.com) · SAPS **10111** when police response is needed.

## Free demo app

```bash
cd parent-compass
python3 -m http.server 8766
# → http://localhost:8766
```

Or open `index.html` directly (no fetch required).

Includes:

1. Sticky safety bar (112 / Childline 116)
2. Situation picker (8 cards)
3. Each card: What’s going on · Try this · Why it helps · Ethics note · When to get outside help
4. Favourites via **localStorage** (device-only)
5. Soft CTA → Gumroad placeholder **R149**

### Situations

Bedtime battles · Sibling conflict · Phone/screen time · Honesty/lying · Chores · Respect/manners · School stress · Apologies/repair
