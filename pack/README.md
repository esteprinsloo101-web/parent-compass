## How to use

1. Read `DISCLAIMER.md`.
2. Pick the situation that matches today.
3. Skim **Try this** once before you walk into the moment.
4. Use a worksheet after (or with) the script if you want a written plan.
5. Favourites in the free web demo are optional — pack works offline on paper.
